✅ Passo 1: Criar Emulador
1 Android Studio já aberto?
Se não, abra: C:\xampp\htdocs\myd_bar_restaurantes\android-studio-project\MyDApp
2 Abra Device Manager
Menu superior: Tools → Device Manager
3 Crie novo dispositivo
Clique em: "Create Device"
Selecione: "Pixel 4"
Clique: "Next"
4 Selecione Android Version
Escolha: API 34 (Android 14)
Clique: "Next" → "Finish"
⏳ Aguarde download (5-10 minutos na primeira vez)
5 Inicie o emulador
Ao lado de "Pixel 4 - API 34", clique no botão ▶️ (Play)
Aguarde o Android iniciar (1-2 min)
✅ Passo 2: Executar App
⏳ O emulador deve estar iniciado antes de prosseguir!
1 Via Menu (Recomendado)
Menu: Run (ou Shift+F10)
Selecione: "Pixel 4 - API 34"
Clique: "OK"

OU

2 Via Terminal/PowerShell
cd c:\xampp\htdocs\myd_bar_restaurantes\android-studio-project\MyDApp ./gradlew installDebug
✅ Se tudo funcionou, o app abre mostrando a tela de login do MyD!
✅ Passo 3: Testar Funcionalidades
1 App carregou com sucesso?
✓ Você vê a tela de login ou menu
✓ Interface está responsiva
✓ Ícones e cores corretos
2 Teste o login
Use um telefone que você criou no sistema
Clique em "Continuar"
3 Teste o rastreamento
Faça um pedido no app
Vá na aba "Pedidos"
Observe atualizações a cada 5 segundos
4 Teste offline
Desative WiFi (Extended controls)
App continua funcionando com cache
Reative WiFi e pedidos sincronizam
✅ Passo 4: Customizar (Opcional)
Mudar URL do servidor
Arquivo: app/src/main/java/.../MainActivity.kt
Linha: 74
Mude de: http://localhost/app-cliente/
Para: http://seu-servidor.com/app-cliente/
Mudar nome do app
Arquivo: app/src/main/res/values/strings.xml
<string name="app_name">Seu Nome Aqui</string>
Mudar cores
Arquivo: app/src/main/res/values/colors.xml
<color name="primary_red">#EA1D2C</color>
Após editar: Save (Ctrl+S) → Run (Shift+F10)
✅ Passo 5: Gerar APK
Debug APK (Para teste)
Use para: Enviar para amigos testarem
Comando:
./gradlew assembleDebug
Localização: app/build/outputs/apk/debug/app-debug.apk
Release APK (Para Play Store)
Antes: Precisar assinar com keystore
Comando:
./gradlew assembleRelease
Localização: app/build/outputs/apk/release/app-release.apk
✅ Passo 6: Publicar (Play Store)
Requisitos
✓ Conta Google Play Developer ($25)
✓ APK assinado (release)
✓ Screenshots (4-6 imagens)
✓ Descrição do app
✓ Política de privacidade
Abrir Google Play Console
💡 Dicas Importantes
Emulador lento? Aumente RAM: Device Manager → Edit → Advanced Settings
App não conecta? Se em emulador, use 10.0.2.2 em vez de localhost
Gradle erro? Execute ./gradlew clean depois tente novamente
Ver logs? View → Tool Windows → Logcat
