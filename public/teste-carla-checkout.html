2. Backend retorna: navigate_to = "checkout"
   → Frontend chama: proceedToCheckout()
   → Aplica pagamento selecionado
   
3. Backend retorna: navigate_to = "address_form"
   → Frontend chama: showProfile()
   
4. Backend retorna: navigate_to = "confirm_order"
   → Frontend chama: confirmOrder()
