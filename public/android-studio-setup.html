🤖 MyD App - Android Studio Setup

Guia passo a passo para abrir, compilar e testar seu app Android

📋 Passo 1: Verificar Requisitos

1

Verificar Android Studio

Você precisa ter Android Studio instalado

Android Studio 2022.3+
Android SDK instalado
Java 11+ (incluído no AS)
4GB RAM mínimo

📂 Passo 2: Abrir Projeto

1

Inicie Android Studio

Abra o aplicativo Android Studio

2

Clique em "Open"

Selecione: File → Open (ou Ctrl+O)

3

Navegue até a pasta do projeto

c:\xampp\htdocs\myd_bar_restaurantes\android-studio-project\MyDApp
4

Clique em "OK"

Android Studio vai abrir o projeto

⚙️ Passo 3: Sincronizar Gradle

⏳ Aguarde 2-3 minutos para Android Studio sincronizar o Gradle
1

Android Studio sincroniza automaticamente

Você verá uma barra de progresso no topo

2

Se pedir para atualizar, clique "Update"

Deixe Android Studio baixar as dependências

3

Se der erro, sincronize manualmente

File → Sync Now (ou Ctrl+Shift+O)

📱 Passo 4: Configurar Emulador

A

Criar novo emulador

Tools → Device Manager → Create Device

  • Device: Pixel 4
  • API: 34 (Android 14)
  • RAM: 1-2GB
B

Ou conecte dispositivo físico

Ative "Depuração USB" nas configurações do celular

🚀 Passo 5: Executar App

1

Clique em "Run" (Shift+F10)

Menu superior ou barra de ferramentas

2

Selecione o emulador ou dispositivo

Android Studio listará as opções disponíveis

3

Clique em "OK"

Android Studio compilará e instalará o app

✅ Sucesso! O app abrirá mostrando http://localhost/app-cliente/

🐛 Solução de Problemas

❌

"Gradle sync failed"

Solução:

1. File → Invalidate Caches → Restart 2. Aguarde Android Studio reiniciar 3. Gradle sincronizará automaticamente
❌

App não consegue conectar em localhost

Se estiver em emulador, mude a URL em MainActivity.kt:

// De: webView.loadUrl("http://localhost/app-cliente/") // Para: webView.loadUrl("http://10.0.2.2/app-cliente/")
❌

"Cannot find SDK"

Configure o SDK:

File → Project Structure → SDK Location → Aponte para seu Android SDK
