  🔐 FLUXO DE AUTENTICAÇÃO
═══════════════════════════════════════════════════════════════════

1. INICIALIZAÇÃO:
   ✓ Ler firebase-config.json (Service Account)
   ✓ Verificar cache de Access Token

2. JWT GERAÇÃO (se token expirado):
   ✓ Header: { alg: RS256, typ: JWT }
   ✓ Payload: { iss, scope, aud, exp, iat }
   ✓ Sign: RS256 com private_key
   ✓ Resultado: JWT assinado

3. OAUTH2 EXCHANGE:
   ✓ POST https://oauth2.googleapis.com/token
   ✓ grant_type: urn:ietf:params:oauth:grant-type:jwt-bearer
   ✓ assertion: JWT
   ✓ Receber: access_token

4. CACHEAR TOKEN:
   ✓ Cache::put('firebase_access_token', $token, 55min)

5. USAR TOKEN:
   ✓ Header: Authorization: Bearer {$accessToken}
   ✓ POST https://fcm.googleapis.com/v1/projects/{id}/messages:send

═══════════════════════════════════════════════════════════════════
  📞 SUPORTE RÁPIDO
═══════════════════════════════════════════════════════════════════

Problema: "Firebase error" Status 400
→ Token FCM inválido ou não registrado
→ Solução: Verificar se app rodou registerFCMToken()

Problema: APK não compila
→ Gradle cache corrompido
→ Solução: Build → Clean Project → Rebuild

Problema: Permissão negada no Android
→ Falta POST_NOTIFICATIONS
→ Solução: Já incluída em AndroidManifest.xml

Problema: Conexão recusada
→ Servidor Laravel não rodando
→ Solução: php artisan serve

Problema: Token não registra na API
→ IP errado ou firewall bloqueando
→ Solução: Verificar IP em MainActivity.kt
