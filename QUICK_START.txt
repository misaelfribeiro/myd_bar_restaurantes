   2. File → Open → MyDApp folder
   3. Build → Build APK(s)
   4. Sucesso em: app/build/outputs/apk/debug/

📦 INSTALAR (1 min):
   adb install -r "app\build\outputs\apk\debug\app-debug.apk"
