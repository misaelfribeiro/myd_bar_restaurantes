# 🤖 Assistente de IA - Configuração

## Como obter sua API Key do Google Gemini (GRATUITA):

1. Acesse: https://makersuite.google.com/app/apikey
2. Clique em "Create API Key"
3. Copie a chave gerada
4. Cole no arquivo `public/app-cliente/js/ai-assistant.js` na linha 10:

```javascript
this.apiKey = 'SUA_CHAVE_AQUI';
```

## Recursos da IA:

✅ **Conversação natural** - Entende contexto e conversa de forma humana
✅ **Busca inteligente** - Encontra produtos baseado em descrições vagas
✅ **Status de pedidos** - Consulta e informa status dos pedidos
✅ **Sugestões proativas** - Sugere produtos baseado no histórico
✅ **Memória de contexto** - Lembra da conversa anterior
✅ **Multi-idioma** - Pode responder em português brasileiro natural

## Exemplos de uso:

🗣️ "Oi, tudo bem?"
🤖 "Oi! Tudo ótimo! O que você tá com vontade de comer?"

🗣️ "Tô com fome, quero algo rápido"
🤖 "Que tal um lanche? Temos hamburgueres deliciosos! Vou mostrar as opções."

🗣️ "Onde tá meu pedido?"
🤖 "Deixa eu verificar pra você! Consultando seus pedidos..."

🗣️ "Quero uma pizza grande de calabresa com borda"
🤖 "Ótima escolha! Procurando pizzas de calabresa com borda recheada..."

## Limites gratuitos:

- 60 requisições por minuto
- 1500 requisições por dia
- Totalmente gratuito para uso pessoal

## Privacidade:

- Os dados não são armazenados pelo Google para treinamento
- A conversa fica apenas no navegador do usuário
- Você controla todos os dados
